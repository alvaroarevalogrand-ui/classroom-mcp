# Privacy Policy / Política de privacidad

_Last updated / Última actualización: 2026-11-12_

## English

**Classroom MCP** is a personal, open-source tool that lets a single user read their own Google Classroom data and upload their own assignment files to their own Google Drive, through an MCP server that runs locally on that user's computer.

**Data accessed.** After the user authorizes it with their own Google account, the app uses these scopes: Classroom courses, coursework, course materials and announcements (read-only); Google Drive (read-only); and `drive.file` (only files created by the app itself, used to upload assignments).

**How data is used.** Data is requested only when the user runs a command, and is used only to show it to that user or to carry out the action they asked for.

**Storage.** The OAuth token is stored only in a local file (`token.json`) on the user's computer. The app has no server and no database, and does not send data to the developer or to any third party. Downloaded files are saved locally.

**Sharing and selling.** Google user data is never sold, shared, transferred or used for advertising or for training machine-learning models. The app's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Retention and revocation.** The user can delete `token.json` at any time and can revoke access at <https://myaccount.google.com/permissions>.

## Español

**Classroom MCP** es una herramienta personal y de código abierto que permite a un único usuario leer sus propios datos de Google Classroom y subir sus propias entregas a su Google Drive, mediante un servidor MCP que se ejecuta localmente en el ordenador de ese usuario.

**Datos a los que accede.** Tras la autorización del usuario con su cuenta de Google, la app usa estos permisos: cursos, tareas, materiales y anuncios de Classroom (solo lectura); Google Drive (solo lectura); y `drive.file` (solo archivos creados por la propia app, para subir entregas).

**Uso de los datos.** Los datos se solicitan solo cuando el usuario ejecuta un comando y se usan únicamente para mostrárselos a él o realizar la acción que ha pedido.

**Almacenamiento.** El token OAuth se guarda solo en un archivo local (`token.json`) en el ordenador del usuario. La app no tiene servidor ni base de datos y no envía datos al desarrollador ni a terceros. Los archivos descargados se guardan en local.

**Compartir y vender.** Los datos de usuario de Google no se venden, comparten ni transfieren, ni se usan para publicidad ni para entrenar modelos de aprendizaje automático. El uso de la información recibida de las API de Google cumple la [Política de datos de usuario de los servicios de API de Google](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de uso limitado.

**Conservación y revocación.** El usuario puede borrar `token.json` en cualquier momento y revocar el acceso en <https://myaccount.google.com/permissions>.

**Contacto.** alvaroarevalogrand@gmail.com
